## The number that was holding A07

```text
Design Template floor grid:  1585.4 × 667.5   aspect 2.375
Rejected prototype (A06):     740   × 363     aspect 2.05
```

**The reference aspect is 2.375, not 2.05.** Measured three ways in the same
session and identical each time: the 52-child grid element, and its two parent
wrappers at 1617.6 × 678.9 (2.382) and 1675 × 699 (2.396). The floor is centred
at x = 960 on a 1920 canvas, dead centre.

So the *direction* in the old matrix survives — production's octagon is too
narrow and too round, and must become wider and shallower — but the **target was
wrong by 0.325 of aspect**, about 16%. An octagon built to 2.05 would have been
visibly rounder than the approved design, and the error would have looked like
the builder's.

## What this changes for the queue

- **A07** may proceed on the *direction* it already had, but its target aspect is
  **2.375**, not 2.05. Building to 2.05 is now a known error rather than an open
  question.
- **A09** (fighter composition) gains real numbers: two symmetric plinth pairs
  flanking the crown at y ≈ 649–665, centres at x 557/1363 and 619/1301 on a
  1920 canvas. The original matrix's finding — that production has no fighter
  composition at all, only scattered cell avatars — is about production and is
  unaffected by the reference dispute.
- **A11** shipped against this same reference and is consistent with it: the
  reference phase panel is 278 × 124, and the panel's height is what A11 was
  about. Production measured 245.6 tall before the card and 245.1 after, so the
  height gap to the reference is real and still open — A11 fixed which clock the
  panel shows, not its overall size.

## Reproducing this

```bash
cd ops/reference/design_arena
python -m http.server 8795 --bind 127.0.0.1
# open http://127.0.0.1:8795/Chef%20Battles%20Arena%20v2.dc.html at 1920x1080
# floor = the div with exactly 52 children and width > 800
```

Do not remove the `.gitattributes` in that directory. Without its `-text` the
HTML and JS get CRLF on a Windows checkout, every byte offset moves, and the
file measured stops being the file that was exported.
