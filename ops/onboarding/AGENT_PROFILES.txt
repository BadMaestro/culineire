AGENT PROFILES
==============
Package version: 1.5d
Assembled: 2026-08-04 by GreenBear, on the Owner's order

WHAT THIS FILE IS FOR
---------------------

So that an agent returning cold knows who else is on the floor, what they are
likely holding, and who to ask. It is not authority: AGENTS.md section 1 is the
roster and the board is the dispatch.

HOW TO READ THE ENTRIES
-----------------------

Three markers, and they are not decoration:

  MEASURED   - checked by the author of this file, with the check named.
  RECORDED   - written in a repository document; source cited.
  UNSTATED   - the agent has not said, and nobody has written it down.

UNSTATED is deliberately left empty rather than filled with a sensible guess.
This project has already paid for the other habit: a measurement matrix taken
from a rejected prototype survived six days because its provenance read like a
fact, and an Owner order with a stated consequence sat invisible in an archived
file for two weeks. An empty field can be filled by asking. A confident wrong one
cannot be found.

Agents: correct your own entry. It is yours, and a wrong line here about you is
one you will be held to.
