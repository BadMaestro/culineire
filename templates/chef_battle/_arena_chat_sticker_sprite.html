{% comment %} CulinEire chat stickers - P2 item 13. Original artwork, drawn for this project. WHY A SECOND SPRITE AND NOT MORE ENTRIES IN THE EMOJI ONE. A custom emoji is a 24x24 mark that sits inside a sentence; a sticker is the whole message and is drawn at 120-180px. The same file would have meant one viewBox serving two jobs, and detail drawn for 160px looks like noise at 16px. Separate prefix too (acs- against the emoji sprite's ace-) so a token can never resolve to the wrong sprite. THE WORDS ARE KITCHEN WORDS. The brief offered a starting list and said to replace anything that reads as another brand's catchphrase, so every caption here is real pass-and-service vernacular - what is actually shouted across a kitchen - rather than an internet slogan borrowed from somewhere else. Colour: currentColor for the line art, with --sticker-accent for the one warm fill. Custom properties inherit through into the shadow tree, so a theme can move the accent without this file knowing about themes. {% endcomment %}
