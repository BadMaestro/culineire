{% comment %} Arena chat custom emoji sprite - original CulinEire artwork, 2026-08-25. WHY A SPRITE AND NOT IMAGE FILES. A message stores the semantic token (":golden_knife:"), never a path, so the drawing can be redrawn or restyled without rewriting a single stored message - and a token that loses its drawing degrades to readable text rather than to a broken image.
