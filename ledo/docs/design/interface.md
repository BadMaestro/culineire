# LEDO Drive interface

The preview uses a restrained dark travel-service design with cool blue as the
only accent. It is independent of the CulinEire visual system.

The supported layout classes are desktop, tablet and mobile. At 900 pixels the
hero, price, booking and FAQ sections become single-column; at 620 pixels form
fields and footer content also stack. Interactive controls retain visible focus,
the page has a skip link, and motion is disabled when the operating system asks
for reduced motion.

The landing page contains no third-party fonts, scripts, maps, analytics or
trackers. All visible claims are limited to the route and request workflow that
the project plan identifies as confirmed.
